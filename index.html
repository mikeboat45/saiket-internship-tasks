Saiket Systems Web Development Internship — Project Showcase

Welcome to my internship project portfolio.
Over the past weeks at Saiket Systems, I have worked on practical frontend development tasks designed to strengthen my skills in HTML, CSS, JavaScript, Mobile Responsive Design and UI development.
This page highlights each project I completed — from simple layouts to dynamic applications — along with the key lessons I gained throughout the journey.

Projects

Tech Event Website

For a fictional event called AI Future Summit 2025, I designed a multi-section webpage with a functional top navigation bar. This task allowed me to explore UI consistency, smooth scrolling, spacing, and intuitive user flow.

Event Registration Form

A registration form with multiple input types, simple validation, and a clean layout. This was where I faced my biggest css challenge — implementing a glowing card effect that required customizing borrowed designs into my own.

Interactive Blogging Platform

A dynamic blogging platform where users can create, edit, and delete posts. The app uses JavaScript DOM manipulation and localStorage to handle data. I learned how to build real interactive features across multiple pages.

Personal Portfolio Website

A fully responsive portfolio website using HTML and CSS, showcasing my skills, background, and sample work. This task strengthened my understanding of page structure, layout techniques, and clean design principles

E-commerce Website

This project focused on creating a visually appealing product page for a fictional phone store. I practiced responsive layouts, product sections, call-to-action elements, and improved my control over Flexbox.

You can read more about each project HERE!

What I Learned

  • HTML & CSS Mastery: I gained strong confidence in building clean layouts, understanding semantic HTML, and designing responsive pages with Flexbox and Grid.
  • JavaScript for Real Applications: I learned how to use JavaScript to manipulate the DOM, handle forms, validate input, respond to user actions, and store/retrieve data using localStorage.
  • Problem-Solving & Debugging: Across each task, I faced challenges — especially with responsive design and JavaScript logic — but learned to solve them through documentation, testing, and breaking down problems step-by-step.
  • Design Thinking & UI Decisions: Through repeated design iterations, I gained a better sense of spacing, typography, visual hierarchy, and creating user-friendly interfaces.
  • Building Multi-Page Flows: how to connect pages logically, pass data through URL parameters, update content dynamically, and build a simple but real-world workflow
